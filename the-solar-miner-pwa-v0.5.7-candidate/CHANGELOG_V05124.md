# Owner PWA 0.5.124

- Each registered miner now has a named top-level tab, including when it is the only miner.
- Miner connection, last communication, protocol, and readings are grouped under Situation.
- Miner load name and power characteristics are exposed under Configuration and System.
- Home uses the same recent-communication rule as the miner panel and scopes breaker telemetry to the matching miner.
- Historical power, consumption, and battery graph is expanded by default; future forecast values are no longer extrapolated into past measurements.
