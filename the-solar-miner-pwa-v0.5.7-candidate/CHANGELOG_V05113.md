# Solar Miner PWA 0.5.113

- Clicking a row in the local network results opens the device details editor.
- Details show the observed IP and MAC, discovered name, manufacturer, model, recognized Gateway device, and discovery methods.
- Owners can save or rename a device in the Gateway inventory using its MAC as the stable key.
- Saving verifies that the MAC is seen in a fresh scan; an ambiguous MAC-to-IP result never overwrites the saved IP.
