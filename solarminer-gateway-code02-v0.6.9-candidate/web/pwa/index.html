SOFTWARE DO GATEWAY

Atualizações assinadas

OWNER

Indica um repositório público HTTPS autorizado pelo administrador do dispositivo. O Gateway consulta apenas o manifesto e o pacote de lançamento, valida a assinatura Ed25519 e não executa código-fonte do repositório.

A verificação só começa após ação explícita do Owner.
Estado de confiança: uma resposta HTTP não confirma identidade; só uma assinatura válida e a fingerprint completa o fazem. Estados DEMO locais não são apresentados como comandos LIVE. A aplicação de uma atualização exige versão validada, preflight de recuperação independente e confirmação explícita de um Owner.
