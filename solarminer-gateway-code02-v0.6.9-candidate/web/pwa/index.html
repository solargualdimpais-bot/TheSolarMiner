EQUIPAMENTO FÍSICO

Ligações de leitura

OWNER · SÓ LEITURA

As ligações são iniciadas pelo Gateway. Os segredos Tuya e Tesla ficam no Gateway e nunca são devolvidos à PWA. Não são enviados comandos de controlo aos equipamentos.

Deye trifásico 15 kW · Modbus TCP

A ligação pode confirmar leitura Modbus bruta. O modelo/firmware e o mapa de registos ainda não foram confirmados; não serão apresentados kW ou volts inventados.

Bitmain Antminer S19K Pro · API

O Gateway consulta apenas summary, stats e devs. A API do minerador tem de aceitar ligações do IP do Gateway na rede local.

Dispositivos Tuya · Cloud API

Requer projeto Cloud Development e permissões Tuya para os dispositivos. A configuração aceita até 50 dispositivos; esta versão lê estado e não executa comandos.

Veículos Tesla · Fleet API (só leitura)

Requer uma aplicação Tesla Fleet registada e autorização do titular com os âmbitos mínimos openid, offline_access e vehicle_device_data. O token rotativo é renovado no Gateway. Só são consultados os veículos indicados; localização e comandos não são expostos. Este fluxo requer obter o refresh token na autorização OAuth da aplicação Tesla.

Configuração apenas disponível ao Owner autenticado.
