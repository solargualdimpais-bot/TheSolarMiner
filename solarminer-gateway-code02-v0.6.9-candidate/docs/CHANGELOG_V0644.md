# SolarMiner Gateway CODE02 v0.6.44

- Home production card displays the live PV output in gold and the inverter UPS load beneath it in white, with separate recent trend lines when Gateway history is available.
- Battery area now represents configured parallel battery banks, with editable name, nominal capacity, online state, and discharge cutoff. It explicitly identifies telemetry as inverter sourced and excludes the inverter's cumulative counters and corrected Ah register from the battery capacity display.
- PWA version 0.5.13 is embedded in the Gateway package; all earlier photo, weather, chart, home/floor, Tuya, energy engine, and Owner Gateway console work is retained.
